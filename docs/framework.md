# Java → Full-Stack Discussion Program — Full Framework

A structured curriculum for daily peer learning sessions for Lucy Njenga and Reagan Fwamba.

## 1. Program Overview

**Cadence:**
- Daily core session: 4:00–6:00 AM
- Daily flex session: 1 hour, scheduled around availability
- Friday all-nighter: real-world project build, running into Saturday morning

**Guiding principle — four stages per topic:**
1. Concept – the "why" and mental model
2. Syntax/Tooling – hands-on mechanics
3. Application – build something small
4. Integration – connect to the previous topic and the eventual capstone

## 2. Session Anatomy

### 4–6 AM Core Block
| Time | Segment |
|---|---|
| 4:00–4:10 | Check-in & recap |
| 4:10–4:50 | Concept deep-dive (teaching role rotates) |
| 4:50–5:40 | Hands-on coding |
| 5:40–5:55 | Debrief & document |
| 5:55–6:00 | Set tomorrow's micro-goal |

### Flex Session (1 hr)
Used for: reviewing each other's code, flashcard-style quizzing, catching up, or discussing an external resource together.

### Friday All-Nighter
- First 30 min: define/refine the week's milestone
- Bulk of night: build, split by task, merge via Git regularly
- Last 30–45 min: retro — what worked, what didn't, gaps found

## 3. Curriculum Phases

| Phase | Weeks | Topics | Friday Project Theme |
|---|---|---|---|
| 1 | 1–3 | Java Classes, OOP, Data Structures | CLI tool in pure Java |
| 2 | 4–5 | JVM | Profile/optimize the CLI tool |
| 3 | 6–9 | Spring, Spring Boot, Database | REST API + DB backend |
| 4 | 10–13 | Microservices, DevOps, CI/CD | Containerized microservices + pipeline |
| 5 | 14–18 | MERN, Machine Learning | Full-stack app + ML feature (capstone) |

## 4. Resources Per Phase

**Phase 1:** [Oracle Java Tutorials](https://docs.oracle.com/javase/tutorial/java/index.html), *Head First Java*, [Java Collections docs](https://docs.oracle.com/javase/tutorial/collections/index.html), [NeetCode](https://neetcode.io/)

**Phase 2:** [JVM Specification](https://docs.oracle.com/javase/specs/jvms/se21/html/index.html), *Optimizing Java* (O'Reilly), [Project Valhalla](https://openjdk.org/projects/valhalla/), [Project Loom](https://openjdk.org/projects/loom/)

**Phase 3:** [Spring Framework docs](https://docs.spring.io/spring-framework/reference/), [Spring Academy](https://spring.academy/), [Baeldung Spring Boot](https://www.baeldung.com/spring-boot), [Mode SQL Tutorial](https://mode.com/sql-tutorial/), [Baeldung JPA/Hibernate](https://www.baeldung.com/learn-jpa-hibernate)

**Phase 4:** [microservices.io](https://microservices.io/), [Docker Get Started](https://docs.docker.com/get-started/), [Kubernetes Basics](https://kubernetes.io/docs/tutorials/kubernetes-basics/), [GitHub Actions docs](https://docs.github.com/en/actions)

**Phase 5:** [Full Stack Open](https://fullstackopen.com/en/), [Google ML Crash Course](https://developers.google.com/machine-learning/crash-course), [scikit-learn tutorials](https://scikit-learn.org/stable/tutorial/index.html)

## 5. Productivity Mechanics

- **Roles rotate weekly** — alternate who leads the concept deep-dive
- **Weekly retro** every Sunday/end-of-Friday: what clicked, what needs more time, does the pace still make sense
- **Buffer week** every 4–5 weeks — consolidation only, no new topics
- **Permission to extend a phase** if a topic needs more depth — better to go deep than rush
