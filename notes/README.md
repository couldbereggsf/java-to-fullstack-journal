# Notes

One markdown file per session, organized by phase.

**Naming convention:** `week-XX-day-YY-topic.md`
Example: `week-01-day-01-conditionals.md`

Each note should briefly cover:
- Concepts covered that session
- Key takeaway(s) as discussed
- Any gap found (also logged in the root `teach-back-log.md`)
- Tomorrow's micro-goal

Subfolders map directly to the curriculum phases in `docs/framework.md`:
- `phase-1-foundations/` — Classes, OOP, Data Structures
- `phase-2-jvm/` — JVM internals
- `phase-3-backend/` — Spring, Spring Boot, Database
- `phase-4-distributed-ops/` — Microservices, DevOps, CI/CD
- `phase-5-fullstack-ml/` — MERN stack, Machine Learning
