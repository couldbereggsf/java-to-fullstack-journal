# Retros

Weekly retrospectives, written at the end of every Friday all-nighter (or Sunday).

**Naming convention:** `week-XX-retro.md`

Each retro should answer:
1. What concept clicked fastest, and why?
2. What concept needs more time before moving on?
3. Does next week's plan still make sense, or should the pace adjust?
4. Any topic gaps surfaced during the Friday build (cross-reference `teach-back-log.md`)
